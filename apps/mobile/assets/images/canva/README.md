# Illustrative images (Canva)

Generated with Canva's AI image tool for the app's splash, login banner, trip-planner
banner and as stand-ins for temple, stay and food photos. They are illustrations,
not photographs of the actual places: replace them with real, licensed photos (or
set real `coverUrl`s on listings) before launch. Mapping: `lib/core/widgets/place_images.dart`.

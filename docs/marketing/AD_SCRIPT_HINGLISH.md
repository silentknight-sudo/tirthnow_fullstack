# TirthNow app ad: Hinglish voice-over script

Long-form app walkthrough ad (about 2 min 45 s, 9:16 vertical). It covers the whole flow:
login → home → darshan and aarti → Temple Store → bookings → Tirth AI → planner → Yatra Journey →
trips and family → reels → SOS → download.

## How to make the voice-over in ElevenLabs

- **Model:** Eleven v3. The `[tags]` below are v3 audio tags; v2 models read them aloud, so do not use v2.
- **Voice:** a warm Indian male or female narrator (for example a "Hindi narration" voice from
  the Voice Library). Settings: Stability *Natural*, Speed 1.0.
- **One clip per scene:** paste each scene's **VO** block as a separate generation and name the
  file `01.mp3`, `02.mp3` … The video's timings follow the scene lengths given below.
  Pasting the whole script in one go also works; the scene pauses are already in the text.
- Pronunciation: write "TirthNow" as **"Teerth Now"** and "Tirth AI" as **"Teerth A.I."** if
  the voice reads them wrongly (already done in the paste-ready block at the end).

Tags used: `[excited]` `[warmly]` `[softly]` `[curious]` `[confident]` `[reassuring]`
`[serious]` `[happy]` `[whispers]` `[pause]` `[short pause]` `[long pause]`.
